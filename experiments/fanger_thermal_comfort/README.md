# Fanger / PMV-PPD 四篇文献介绍

## 补充说明：1967 年 Fanger 原始文献

Fanger 1967 年的原始论文 *Calculation of Thermal Comfort: Introduction of a Basic Comfort Equation* 是 PMV 基础舒适方程的重要源头。由于该文献发表时间较早，目前未检索到 DOI，也未找到可直接获取的正式全文内容。不过，其核心理论已经在 Fanger 1970 年专著 *Thermal Comfort: Analysis and Applications in Environmental Engineering* 中得到系统展开，因此实际学习和引用 PMV/PPD 理论时，通常可重点参考 1970 年专著和 1973 年实践论文。

## 1. Fanger 经典热舒适专著

**文件名：** `Thermal comfort  analysis and applications in environmental engineering (Fanger, P. O).pdf`

Fanger 的经典热舒适专著，约 252 页。内容覆盖人体热平衡、舒适方程、PMV/PPD、热环境测量、平均辐射温度计算和工程应用，是 PMV/PPD 理论的核心来源。

## 2. Fanger 1973 年实践论文

**文件名：** `Fanger_1973_Assessment_of_mans_thermal_comfort_in_practice.pdf`

Fanger 1973 年论文，约 12 页。重点讲热舒适的实践评价：空气温度、平均辐射温度、风速、湿度、活动水平、服装热阻六类变量，以及 PMV 七级热感觉量表和 PPD 不满意率曲线。

## 3. ISO 7730:1994 标准预览版

**文件名：** `ISO_7730_1994_preview.pdf`

ISO 7730:1994 标准预览版，约 12 页。主题是用 PMV 和 PPD 评价中等热环境，并包含气流不适、可接受热环境、代谢率、服装热阻、计算程序和表格等内容。注意这是 preview，不是完整标准正文。

## 4. 2020 年热舒适模型综述

**文件名：** `Thermal Comfort models and their developments A review (Zhao, Qiantao Lian, Zhiwei Lai, Dayi).pdf`

2020 年热舒适模型综述，约 36 页。梳理 PMV-PPD、双节点模型、多节点模型、自适应模型、睡眠环境、室外环境、老年人、不同人群模型以及数据驱动模型，并讨论各类模型的优缺点和发展方向。
